# hayoungbong.github.io

Personal academic homepage of Hayoung Bong (NASA GISS).

- Content is in `index.html`; styles in `assets/site.css`; scripts in `assets/theme.js` (runs first: language + day/night theme) and `assets/site.js`.
- The page has a strict Content-Security-Policy: no inline `<script>`, no `style="..."` attributes, no third-party hosts. Put new CSS/JS in the asset files.
- Images live in `assets/` (banner and research images: NASA, public domain).
- Pushing to `master` publishes to https://hayoungbong.github.io within a minute or two.
- The previous site is kept on the `old-site` branch.
